# Sapa Jol / SafeRoute — Design System

Единый источник правды по дизайну. Все новые компоненты и правки UI обязаны
соответствовать этому документу. Токены живут в `src/constants/colors.ts` —
если меняешь токен, меняй его там, а не в стилях компонентов.

## 1. Философия

Nothing Phone aesthetic: чистый чёрный, тонкие световые акценты, один
функциональный зелёный акцент. Функция важнее декора: свечение только у
элементов, требующих внимания (FAB, активные статусы). Никаких стеклянных
плиток, дорожных пунктиров и прочих экспериментальных мотивов без согласования.

## 2. Токены (src/constants/colors.ts)

### Цвета
| Токен | Значение | Использование |
|---|---|---|
| `bg.primary` | `#000000` | фон приложения и карты |
| `bg.secondary` | `#0F0F0F` | карточки, панели, диалоги |
| `bg.tertiary` | `#1A1A1A` | инпуты, вложенные элементы |
| `bg.glass` | `rgba(255,255,255,0.04)` | лёгкие подложки поверх карты |
| `brand.primary` | `#2ECC71` | единственный основной акцент |
| `brand.glowStrong` | `#2ECC7150` | свечение активных элементов |
| `text.primary` | `#FFFFFF` | основной текст |
| `text.secondary` | `#8A8A8A` | описания, подписи |
| `text.muted` | `#666666` | плейсхолдеры, дизейбл |
| `border` | `rgba(255,255,255,0.08)` | стандартная рамка |
| `alert.critical` | `#FF3B30` | опасно / закрыто |
| `alert.high` | `#FF9500` | предупреждение / осторожно |
| `alert.medium` | `#FFD60A` | заметность |
| `alert.low` / `success` | `#2ECC71` / `#34C759` | ок |
| `alert.info` | `#0A84FF` | информационное |

Правило: зелёный — действия и «хорошо», оранжевый — внимание, красный —
опасность. Не перекрашивать смыслы.

### Отступы / радиусы
- Spacing: `4 / 8 / 16 / 24 / 32 / 48` (xs…xxl). Не придумывать промежуточные.
- Radius: `4 / 8 / 12 / 16 / 24 / 32 / 999`. Пилюли — `Radius.full`.

## 3. Типографика

Системный шрифт (казахские глифы обязаны работать). Размерная сетка:

| Роль | Размер / вес |
|---|---|
| Заголовок экрана | 26–34 / 900 |
| Заголовок карточки | 16 / 700 |
| Основной текст | 14–15 / 400–600 |
| Подпись, описание | 12–13 / 400–600 |
| Микро-лейбл (uppercase) | 10 / 800 / letterSpacing 1.5 |

Body-текст ≥ 13px. Uppercase-лейблы — только `fieldLabel`-паттерн.

## 4. Компоненты (паттерны)

### Кнопки
- **Primary**: фон `brand.primary`, текст `bg.primary`, вес 900, `paddingVertical 16`, `Radius.lg`. Свечение не обязательно.
- **Secondary/Back**: `bg.glass` + рамка `border`, текст `text.secondary`.
- **Иконочная (map controls)**: 44×44, `bg.secondary`, рамка `border`, иконка 20.
- Кнопка-действие не может быть без текста. Диалоговые кнопки — текстовые (см. AppDialog).

### Диалоги (AppDialog)
Нативный alert-стиль: иконка-чип 56, жирный заголовок 17, сообщение 13.5,
кнопки текстовые строками через hairline (`Colors.divider`). Полноширинные
цветные плашки запрещены.

### Тосты
Неблокирующий фидбек (Toast.tsx): пилюля снизу (bottom ~118), фон `rgba(15,15,15,0.96)`,
иконка + текст 13.5/600, живёт 2.6 с. Успех — не диалог, а тост.

### Поля ввода
`bg.tertiary`, рамка `border`, `Radius.lg`, слева иконочный блок 40×44 с
иконкой `brand.primary`, `paddingVertical 14`. Лейбл — микро-uppercase.
Ошибка — рамка `alert.critical` + текст 11 снизу.

### Карточки-переключатели (роль, трасса)
`bg.secondary` + рамка; выбранная = сплошная заливка `brand.primary`, текст
`bg.primary`. Радио-кружок справа (22px, внутренняя точка 10).

### Карусель онбординга
Слайды: круглая подложка 140 (radius 70, `bg.glass`, рамка `accent+30`),
иллюстрация 100, заголовок 32/accent, subtitle 14 uppercase, описание 15.
Далее → полноэкранный AUTH (см. ниже). НЕ встраивать форму в карусель.

### Экран формы (AUTH)
Отдельный полноэкранный экран: сегмент-контрол сверху (Тіркелу/Кіру),
контент скроллится, **панель действий закреплена снизу** (back + primary
на всю ширину). Никогда не прятать панель за клавиатурой: Android —
adjustResize (KAV behavior=undefined), iOS — behavior='padding'.

### Оверлеи карты
Top bar + фильтры — один вертикальный стек (top: 46) с gap 8. Каждый
элемент — самостоятельная стеклянная карточка `rgba(8,10,14,0.92)`.
Кнопка FAB 60px — единственный зелёный акцент справа снизу.

## 5. Иконки

Ionicons (`@expo/vector-icons`). Эмодзи в UI запрещены. Размеры: 20 — кнопки,
24 — карточки/табы, 26 — табы active, 15–18 — микрокомпоненты.

## 6. Язык и тексты

- Всё через `useT()` + `src/i18n/translations.ts` (kk + ru, ключи в обоих
  блоках, дубль-ключи недопустимы). Хардкод строк в JSX — запрещён.
- Функциональные тексты — казахский + русский, без латинских `i` в
  казахских словах.
- `useSettings` — глобальный zustand-стор: смена языка применяется мгновенно.

## 7. Формат и верификация

- Prettier (`.prettierrc.json`), коммит-хуки — lint-staged.
- Перед сборкой: `npx tsc --noEmit` + `npx expo export --platform android`
  (должен собрать hbc без ошибок).
- Скриншот новых экранов в PR обязателен для ревью дизайна.

## 8. Заимствование компонентов (21st.dev MCP и др.)

Брать чужие компоненты можно только после приведения к токенам выше
(цвета/радиусы/шрифты — подставить свои). Для подключения 21st.dev MCP:
добавить сервер в MCP-конфиг клиента (например `npx -y @21st-dev/mcp`
в списке MCP-серверов) и перезапустить IDE — после этого компоненты будут
доступны в чате. Для React Native проверять: (1) RN-совместимость (без
DOM API), (2) зависимости не тянут web-библиотеки, (3) переделка под
наши токены дешевле, чем написание с нуля.
